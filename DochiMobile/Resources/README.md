# Mobile visual assets

The seven `Avatar_*` image sets are previews rendered from the bundled CC0 VRM
models documented in [`Dochi/Resources/Models/README.md`](../../Dochi/Resources/Models/README.md).
They retain the same model names and are used only as selectable 2D conversation
avatars in the iOS target.

`AppIcon.appiconset/AppIcon-1024.png` is an original Dochi app icon generated for
this project on 2026-07-12. It does not reuse third-party logos or text.
